# 张张便签 (DaniNote)

一个美观实用的桌面便签程序，支持待办事项管理、富文本编辑、窗口自定义等功能。

## 功能特点

- 便签管理：新建、编辑、删除、置顶便签
- 待办事项：添加待办、勾选完成、查看历史
- 窗口自定义：拖拽调整大小、置顶、透明度调节
- 毛玻璃效果：Windows Acrylic 模糊背景
- 数据持久化：SQLite + JSON 混合存储
- 富文本编辑：加粗、倾斜、下划线、字号调整
- 列表功能：有序列表、无序列表

## 技术栈

- GUI 框架: PySide6 (Qt for Python)
- 打包工具: PyInstaller
- 数据库: SQLite3
- 平台: Windows 10/11

## 快速开始

双击运行 `run.bat` 或直接运行打包后的 exe 文件。
