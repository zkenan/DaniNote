## 关键技术点
- `WM_NCHITTEST` 返回 HT 值后，Windows 自动设置对应的调整大小光标
- 坐标 `lParam` 低16位/高16位需做有符号转换（`>= 0x8000` 时减 `0x10000`）
- 标题栏拖拽仍由 `eventFilter` 处理（HTCAPTION 会与 Qt 按钮冲突）
- `WS_THICKFRAME` + `SWP_FRAMECHANGED` 组合确保原生 resize 逻辑激活
