# Znote 4个Bug修复 - 2026-05-29

## 修改文件
- `F:\qclaw\Znote\main.py`
- `F:\qclaw\Znote\src\views\main_window.py`

## 4个问题及修复

### 问题1：启动隐藏到托盘
**根因**：`main.py` 中当 tray 可用时 `window.show()` 不执行，窗口直接隐藏。
**修复**：去掉 `if/else` 判断，直接 `window.show()`。

### 问题2：待办时间设置需要下拉选择
**根因**：原有 `QDateTimeEdit` 只支持手动输入/日历弹窗，缺少快捷预设。
**修复**：在 `QDateTimeEdit` 旁边添加 `QComboBox` 快捷预设下拉（今天18:00、明天09:00等7个选项），选中后自动填充 `QDateTimeEdit`。
- 新增 `self._time_preset_combo` 控件
- 新增 `_on_time_preset_selected()` 方法计算相对日期并设置 `QDateTimeEdit`
- 新增 `QComboBox` import 和样式

### 问题3：设置面板无关闭按钮 + 图标不匹配
**根因**：设置弹窗（主题颜色）没有关闭按钮（透明度弹窗有关闭按钮但设置弹窗没有）；设置图标用 ⚙ 不够直观。
**修复**：
- 给设置弹窗头部添加 `×` 关闭按钮（`popupCloseBtn`），与透明度弹窗一致
- 设置按钮图标从 ⚙ 改为 🎨（调色板），更贴合主题颜色功能
- 弹窗高度从 130 调整为 150 以容纳关闭按钮行
- 新增 `popupCloseBtn` 样式

### 问题4：窗口拖拽调整大小无效
**根因**：`nativeEvent` 中非边缘区域返回 `True, 1`（HTCLIENT），PySide6 的 `nativeEvent` 返回 `(True, result)` 表示"已处理该消息"，但返回 HTCLIENT=1 会覆盖系统默认处理，导致标题栏拖拽和客户区事件处理异常。
**修复**：非边缘区域改为 `return False, 0`，不拦截该消息，让系统默认处理（包含 HTCLIENT 和标题栏拖拽等所有正常行为）。只拦截边缘区域返回对应的 HT 边框值。

## 语法验证
`python -m py_compile` 对 `main.py` 和 `main_window.py` 均通过。
