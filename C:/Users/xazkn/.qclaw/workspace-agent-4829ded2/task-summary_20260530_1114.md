修复 DaniNote 编辑器字号和列表相关的 5 个问题。

## 关键结论
- 根因：Qt QTextListFormat 的标记渲染不跟随 QTextCharFormat 的字号设置，无论怎么改都不行
- 最终方案：废弃 QTextList，改用纯文本前缀（"1. " / "• "），标记是普通文字，字号天然跟随
