## 目标
修复 Znote 便签应用的两个问题：
1. 颜色不统一（切换主题后侧栏颜色不变）
2. 窗口不能通过拖拽调整大小

## 修改文件
`F:\qclaw\Znote\src\views\main_window.py`

## 修改内容

### 修复 1：窗口拖拽调整大小（nativeEvent）
**根因**：
- `WM_NCCALCSIZE` 返回 `True, 0` 会告诉系统"非客户区大小为 0"，这吃掉了 Windows 原生的边框区域，与 `_enable_native_resize()` 中设置的 `WS_THICKFRAME` 标志冲突
- `WM_NCHITTEST` 在非边缘区域返回 `False, 0` 而不是 `HTCLIENT(1)`，导致系统不知道如何处理这些区域的鼠标消息

**修复**：
- 移除 `WM_NCCALCSIZE` 的拦截（不再返回 `True, 0`），让系统自己管理非客户区
- `WM_NCHITTEST` 非边缘区域改为返回 `(True, 1)` 即 `HTCLIENT`
- 边缘检测逻辑保持不变

### 修复 2：颜色不统一（Sidebar._style）
**根因**：
- `Sidebar._style()` 方法硬编码了暖阳主题的颜色值（`#FFF8E7`, `#E8DCC8` 等）
- 虽然 `apply_theme()` 会正确设置主题色，但 `_style()` 返回的硬编码字符串可能在某些情况下覆盖主题色

**修复**：
- 将 `Sidebar._style()` 改为返回空字符串
- 所有颜色完全由 `apply_theme(t)` 统一管理，确保主题切换时所有组件颜色同步更新
