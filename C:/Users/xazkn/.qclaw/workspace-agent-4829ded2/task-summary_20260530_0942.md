# Znote/DaniNote 列表Bug修复 (2026-05-30 09:42)

## 目标
修复4个问题：①增大字号先跳最小 ②有序列表序号全为1 ③无序列表缩进 ④列表标记字号不跟随

## 根因分析
1. **字号跳最小**: fontPointSize()=0时取base+2逻辑虽对，但 setCurrentCharFormat 只影响后续输入，对已有文字不生效
2. **序号全为1**: _insert_list 中循环调用 createList()，每次创建新列表对象，每个块在独立列表里
3. **缩进问题**: 之前去掉setIndent后标记无法正常显示；需要设indent(1)但不在toggle时递增
4. **标记字号**: Qt已知限制，ListMarker字号由QTextListFormat控制，需测试HTML方案

## 修复方案
- 完全重写 note_editor.py 的列表和字号逻辑
- `_insert_list()`: 只调用一次 createList()，Qt自动管理后续块编号
- `_remove_list()`: 从后往前遍历移除所有列表块
- `_font_larger/smaller()`: 有选区时逐块 mergeCharFormat
- 写了 _test_list_font.py 测试4种方案验证列表标记字号
